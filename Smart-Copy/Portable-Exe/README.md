# Smart Copy — Portable Edition

This folder contains the standalone, portable single-file executable for **Smart Copy**.

## Files
- **\SmartCopy.exe\**: Standalone, fully offline OCR selection utility.

## How to Run
1. Double-click **\SmartCopy.exe\**.
2. Smart Copy will silently launch into your Windows system tray.
3. Press **Left Ctrl + Left Alt + Right-Click** anywhere on your screen to trigger the two-point text selection.
4. Click the start of any text, then click the end of the text.
5. The recognized text is automatically copied to your clipboard!

## Requirements
- Windows 10 (version 1809 or higher) / Windows 11 (64-bit)
- No .NET runtime installation required (all runtimes & Tesseract OCR 5 are bundled inside the portable executable).
