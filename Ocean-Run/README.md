# Ocean Run 🌊⚓

A mobile-first, single-page HTML5 maritime endless-runner built for quick play from a GitHub Pages link.

## Play
If GitHub Pages is enabled for this repository, open:
https://xaviourzone.github.io/Articles/Ocean-Run/

## Controls
- Swipe left/right: steer between three lanes
- Swipe down: slide under danger
- Tap FIRE: shoot marked arcade targets
- Collect glowing chart books to trigger knowledge checkpoints
- Answer maritime mini-questions to earn points

## Features
- 60-second voyage with a lighthouse finish
- Procedural Canvas ocean, patrol craft, containers, buoys, targets, wake/glint effects, and storm progression
- Maritime knowledge prompts about AIS, nautical miles, echo sounders, IALA buoyage, knots, charts, and safe passage
- Score, distance, timer, collision penalties, quiz rewards, restart, and WhatsApp/share challenge
- No external libraries, backend, build step, or network assets required

## Files
- `index.html` — complete self-contained playable game
- `assets/ocean-logo.svg` — lightweight SVG title mark

All game actions are fictional arcade mechanics and are not intended as real-world navigation guidance.
